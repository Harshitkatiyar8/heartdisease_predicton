About the Model

Technical overview of the machine learning architecture.

Logistic Regression is a supervised machine learning algorithm commonly used for binary classification. In this project, it is used to predict the model's heart disease classification based on the provided health parameters.

Numerical inputs (such as Age, Blood Pressure, Cholesterol, Max Heart Rate, and Oldpeak) are transformed using StandardScaler to ensure zero mean and unit variance. Categorical variables are converted via One-Hot Dummy Encoding and aligned to the exact 15-feature matrix defined during training.
